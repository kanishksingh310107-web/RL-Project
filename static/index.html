    Markov Decision Process (MDP) Definition: $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)$
    
          
      
            
    • State Space ($\mathcal{S}$): Normalized continuous vectors $s_t \in [0, 1]^d$ representing traveller interests, energy levels, physical stamina, climate tolerance, and budget bandwidth.
      • 
            
    • Action Space ($\mathcal{A}$): Discrete set of candidate destinations and itinerary structures $\mathcal{A} = \{a_1, a_2, \dots, a_K\}$.
      • 
            
    • Transition Function ($\mathcal{P}$): State transition probability $\mathcal{P}(s_{t+1} \mid s_t, a_t)$ updated through post-trip feedback, activity ratings, and preference shifts over time.
      • 
            
    • Reward Function ($\mathcal{R}$): Multi-criteria objective function:
              
      R(s, a) = w_int * S_interest + w_clim * S_climate + w_bud * S_budget + w_pace * S_pace - Penalty_masks
            
      • 
            
    • Hard Safety & Constraint Masks: Extreme negative reward ($-\infty$) applied to destinations or activities violating user medical constraints, severe mobility limits, or explicit negative avoidances.
      •
